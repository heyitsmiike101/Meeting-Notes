# Meeting Notes bridge workflow

Read the transcript and produce structured notes for the meeting-notes
library. Keep the transcript as the source of truth. Preserve uncertainty;
never fill gaps with plausible names, dates, or commitments. Mark an item as
an action only when the group agrees it is work to do. Write a polished,
readable meeting_notes narrative and separately identify participants, key
points, decisions, action items, open questions, risks, and next steps. Use
null for an action owner or due date unless the transcript states it.
